# AURA Commerce

**واجهة متجر عربية على Telegram لاستقبال الطلبات وإدارتها.**

AURA Commerce يحوّل محادثة Telegram إلى قناة بيع بسيطة لأصحاب المتاجر والخدمات: كتالوج منتجات، طلبات، بيانات تواصل، ولوحة إدارة عبر أوامر Telegram.

## الوظائف الحالية

- كتالوج منتجات مخزّن في SQLite.
- عرض تفاصيل المنتج والسعر للعميل.
- إنشاء طلب مع لقطة لسعر المنتج وقت الطلب.
- جمع رقم الهاتف بمشاركة جهة الاتصال أو استقبال وسيلة تواصل نصية.
- أوامر إدارة محمية بقائمة Telegram user IDs.
- متابعة حالات الطلب: `new`, `contacted`, `confirmed`, `completed`, `cancelled`.
- لا يوجد تحصيل أموال مدمج حالياً؛ لا ينشئ البوت روابط دفع وهمية ولا يعلن أن الطلب مدفوع.
- قاعدة البيانات محلية؛ يلزم تخزين دائم ونسخ احتياطي عند النشر.

## التشغيل

يتطلب Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

عيّن المتغيرات التالية في بيئة التشغيل أو مدير الأسرار:

| المتغير | الوصف |
|---|---|
| `TELEGRAM_BOT_TOKEN` | رمز البوت من BotFather |
| `ADMIN_IDS` | معرفات Telegram الرقمية للإدارة، مفصولة بفواصل |
| `AURA_DATABASE_PATH` | مسار ملف SQLite دائم |
| `AURA_CURRENCY` | رمز العملة المعروض، افتراضياً USD |

ثم شغّل:

```bash
python main.py
```

## أوامر العملاء

- `/start` — البداية
- `/shop` — تصفح المنتجات
- `/cancel` — إلغاء إدخال بيانات الطلب

## أوامر الإدارة

أضف معرف Telegram الرقمي الخاص بك إلى `ADMIN_IDS` قبل التشغيل.

- `/add_product الاسم | السعر | الوصف`
- `/products`
- `/orders`
- `/set_status رقم_الطلب new|contacted|confirmed|completed|cancelled`

## الاختبارات

```bash
python -m unittest discover -s tests -v
```

## ما يلزم قبل البيع الفعلي

1. نشر الخدمة على استضافة دائمة مع تخزين دائم لقاعدة البيانات ومراقبة وإعادة تشغيل تلقائي.
2. ضبط `ADMIN_IDS` وحماية وصول الإدارة.
3. تحديد شروط البيع وسياسة الخصوصية والاحتفاظ ببيانات العملاء.
4. اختيار مزود دفع متاح قانونياً وتجارياً في بلد النشاط، ثم تنفيذ تكامل موثق والتحقق من إشعارات الدفع server-side قبل اعتماد حالة `paid`.
5. اختبار تجربة الطلب مع متجر تجريبي وموافقة صاحب المتجر قبل استقبال عملاء حقيقيين.

هذا الإصدار يستقبل طلبات ويتيح إدارتها؛ لا يدّعي أنه ينفّذ المدفوعات أو أنه مستضاف 24/7.
