# AURA Bot

بوت Telegram عربي لإدارة عرض الخدمات واستقبال طلبات العملاء، مع تخزين محلي للطلبات وإعداد آمن للرمز عبر متغيرات البيئة.

## المتطلبات

- Python 3.10+
- Telegram Bot Token جديد من BotFather

## التشغيل المحلي

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="ضع_الرمز_محلياً"
python main.py
```

PowerShell:
```powershell
$env:TELEGRAM_BOT_TOKEN="ضع_الرمز_محلياً"
python main.py
```

لا تضع الرمز في `main.py` أو GitHub. ملف `.env.example` مرجع فقط، ولا ترفع `.env`.

## الوظائف

- `/start` يعرض لوحة الأقسام العربية.
- كتالوج طلب الخدمات: أتمتة المهام، بوت Telegram للأعمال، تنظيف/تحويل ملفات، تفريغ صوت عربي، لوحات التقارير، وربط الأنظمة.
- تدفق جمع بيانات العميل: الاسم، وسيلة التواصل، وصف الطلب.
- حفظ الطلبات في SQLite بقاعدة `aura_leads.sqlite3` محلية.
- إشعار إداري اختياري عند ضبط `AURA_ADMIN_CHAT_ID`.
- `/cancel` لإلغاء إدخال الطلب.
- الدفع غير مفعّل؛ لا يتم تقديم رابط دفع قبل تكامل بوابة موثوقة.

## إعداد الإشعار الإداري

ضع معرف محادثة Telegram الإدارية في متغير البيئة:
```bash
export AURA_ADMIN_CHAT_ID="YOUR_ADMIN_CHAT_ID"
```

معرّف الإدارة ورمز البوت لا يُضمّنان في الكود أو المستودع. إشعار الإدارة اختياري؛ الطلب يُحفظ في SQLite حتى عند فشل الإشعار.

## قاعدة بيانات الطلبات

- الافتراضي: `aura_leads.sqlite3` في مجلد التشغيل.
- يمكن تعيين مسار مختلف عبر `AURA_LEADS_DB`.
- ملفات SQLite المحلية مستثناة من Git عبر `.gitignore`.
- البيانات تحتوي معلومات تواصل العملاء؛ احمِ ملف القاعدة، وحدّد صلاحيات الوصول، ووفّر نسخة احتياطية آمنة حسب سياسة التشغيل.

## النشر

يتطلب استضافة تدعم عملية Python طويلة الأمد. أضف `TELEGRAM_BOT_TOKEN` و(اختياريًا) `AURA_ADMIN_CHAT_ID` إلى مخزن أسرار الاستضافة، ثم شغّل `python main.py`. لا يوجد رابط تجربة عام أو تشغيل فعلي للبوت مثبت من هذا المستودع وحده.

## الأمان

إذا سبق نشر رمز البوت داخل Git، ألغِه من BotFather عبر `/revoke` وأنشئ رمزًا جديدًا. حذف الرمز من الملف الحالي لا يزيله من تاريخ Git السابق.
